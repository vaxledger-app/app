How to search and export immunization records in VaxLedger

Filter recorded vaccine entries and export the visible immunization ledger as JSON, with clear limits on what the file establishes.

By the VaxLedger project · Published September 9, 2026 · Software guide

On this page

  1. Search by the displayed vaccine label
  2. Read the entry before exporting
  3. Know that the export follows the filter
  4. Check the destination’s requirements separately
  5. Questions about this guide

Search by the displayed vaccine label

The search box filters the labels in the returned immunization list. Start with a short recognizable part of the label and clear the field to restore the full ledger. The entry count describes the current filtered view, not the number of doses in a recommended series.

Read the entry before exporting

Each row presents a label, the available date, source context, status and a code when supplied. These fields describe the returned record. The app does not decide whether an entry meets a school, employment or travel requirement.

  1. Check the search field for an active filter.
  2. Review the number of visible entries.
  3. Inspect the source entries if a label or date needs clarification.
  4. Clear the filter if you intend to export every returned immunization.

Know that the export follows the filter

“Export ledger” creates a JSON file containing the rows currently visible after filtering. The file also labels the source and states that it is not for clinical use. A filtered export can intentionally leave out other returned entries, so keep that distinction clear when using the file later.

Check the destination’s requirements separately

A personal JSON export is not an official vaccination certificate. Ask the receiving organization what form of documentation it accepts and obtain source documentation where required. The public site explains the workflow; live authorized imports remain pending activation.

Questions about this guide

Does exporting include hidden search results?

No. VaxLedger exports the filtered rows. Clear the search first to include all returned entries.

Can the ledger tell me which vaccination is due?

No. The implemented product organizes recorded history and does not calculate schedules or recommendations.
